rest-trans ⚡

Un binaire Go + PostgreSQL = une API REST complète, documentée, avec transactions distribuées, full-text search, vues SQL et temps réel.
Zéro framework · Zéro ORM Go 1.25+ · PostgreSQL 16+ MIT · open source
📦 GitHub 📘 OpenAPI
🧩

Le problème

Construire une API REST robuste, c'est du travail répétitif : routes CRUD, filtrage, pagination, documentation, transactions, temps réel, monitoring, sécurité… Chaque projet réinvente la même roue.

✨

La solution

rest-trans introspectionne votre schéma PostgreSQL et génère automatiquement une API REST complète. Ajoutez une colonne ? L'API se met à jour. Créez une vue ? Elle devient un endpoint. Écrivez une fonction stockée ? Elle devient un RPC.

Fonctionnalités

🧠

Introspection auto

Tables, vues, PKs, FKs, contraintes uniques. Hot reload sans restart.

🔍

Filtrage avancé

20+ opérateurs (eq, like, in, gt…), logiques _and/_or.

🔎

Full-text search

Filtre _fts avec tsvector/tsquery. Ranking automatique, langues configurables par table.

📄

Réponses JSON / CSV

Sélection, tri, pagination, agrégats. Headers Content-Range.

👁️

Vues SQL read-only

Les vues deviennent des endpoints. Mutations automatiquement bloquées (405).

📡

Temps réel (SSE)

Endpoint /_stream, triggers NOTIFY automatiques, console IHM.

🔁

Transactions distribuées

Pattern Saga : staging, commit atomique, TTL configurable.

⏪

Post-commit Rollback

Annuler un commit appliqué. Snapshots, détection de conflits, rollback multi-bases.

📊

RPC & procédures stockées

Appel direct /rpc/ma_fonction avec paramètres JSON.

🛡️

Sécurité intégrée

Permissions via commentaires PG ou config, rate limiting, tables cachées.

📘

Documentation auto

OpenAPI, Swagger UI (/docs), IHM d'administration /.

⚙️

Observabilité

Métriques Prometheus, health checks, logging structuré JSON.
